How it works

From Requirements to Reports in Four Steps

STEP 01

Requirement Analysis

Upload requirement documents; the agent parses them into clear user stories, ready for review.

STEP 02

Test Case Generation

The agent writes test cases from those stories, aiming for full coverage of the paths that matter.

STEP 03

Script Generation

Cases become executable scripts with a visual workflow. Pick devices and run them in parallel.

STEP 04

Execution & Reporting

Every run produces a visual report with step screenshots and video replay, so failures are easy to trace.

Product

What the Dragon Testing Agent Does

Describe a test in plain English. The agent plans the interaction path, executes it on a real device, asks when it is unsure, and saves the result as a script you can replay.

01

Testing Agent

Natural-language test goals become clicks, inputs, swipes and assertions. Start from scratch or extend existing cases step by step.

02

Human in the Loop

Pause at any step, take over manually or add context. The agent picks up from there and finishes the remaining steps.

03

Deterministic Replay

Generated tests are saved as scripts. Regression runs replay them directly — stable results, no model calls, near-zero token cost.

04

Visual Workflows

Test logic is shown as flowcharts you can edit and preview, so complex suites stay readable for the whole team.

05

Extensible Steps

Add API calls, database queries or custom scripts to any step to cover setup, data checks and back-end verification.

06

Evidence-Rich Reports

Pass rates, failure reasons, step screenshots and full video replay for every run. Export for audits and sign-off.

Why Dragon Testing

About

Making Testing Smarter

Dragon Testing builds AI-driven UI test automation. Our first-generation platform combined AI, robotics and model-based testing to automate web, mobile, desktop and hardware-in-the-loop scenarios, and is used by more than a hundred enterprises in finance, rail transit, telecom and enterprise software.

Our second generation puts a large-model testing agent at the center: it reads requirements, writes and runs tests, and turns what it learns into scripts that replay reliably.

We serve customers in the United States with both cloud and on-premises deployment.
